# ワードッチオンライン

友達とオンラインで遊べる、ボードゲーム「[ワードッチ](https://arclightgames.jp/product/651wordocchi/)」風の会話ゲームです。
実際の商品のカード内容（ワード・キジュン）は使用せず、独自に作成したオリジナルのデータを収録しています。

- ブラウザだけで動く静的サイト（GitHub Pagesで公開できます）
- 対戦の同期には Firebase Realtime Database を使用します（無料枠で十分動きます）
- ビルド不要。素のHTML / CSS / JavaScript（ESモジュール）で作られています

## 遊び方（ルール概要）

1. 3〜8人で1部屋に入ります。1人が「親」になります。
2. 親には2枚のカード（キジュン案＋ワード3つ）が配られ、こっそりどちらか一方を今回の「キジュン（お題の基準）」として選びます。子には1枚ずつカードが配られます。
3. 親は最初のワードを1つ選び「暫定チャンピオン」として発表します。
4. 子は自由にワードを出していき、親はキジュンに沿って「チャンピオン vs 新しいワード」を1対1で判定します。勝った方が新チャンピオンになります。
5. 親が良いタイミングで調査を打ち切り、「決選フェイズ」へ。子は今まで出ていないワードの中から、親が選びそうな「優勝ワード」を予想して一斉に提出します。
6. 親が一番ふさわしいと思うワードを選び、それを出した人が優勝。最後にキジュンを公開してみんなでワイワイ話しましょう。

## セットアップ（公開までの手順）

### 1. Firebaseプロジェクトを作る

1. [Firebase コンソール](https://console.firebase.google.com/)にアクセスし、Googleアカウントでログインします。
2. 「プロジェクトを追加」から新規プロジェクトを作成します（Googleアナリティクスは不要ならオフでOK）。
3. 左メニューの「構築」→「Realtime Database」を選び、「データベースを作成」します。ロケーションは任意、セキュリティルールはいったん「テストモードで開始」でも構いません（後述のルールに置き換えます）。
4. 左メニューの「プロジェクトの概要」の歯車 →「プロジェクトの設定」→ 下の方の「マイアプリ」で「ウェブアプリを追加」（`</>` アイコン）をクリックし、アプリ名を適当に入力して登録します。
5. 表示された `firebaseConfig` の内容をコピーします。

### 2. 設定ファイルに貼り付ける

[`src/firebase-config.js`](src/firebase-config.js) を開き、`firebaseConfig` の中身を手順1でコピーした値に書き換えて保存します。

このAPIキー等は秘密鍵ではなく公開されて問題ない識別子なので、そのままGitHubにコミットして大丈夫です（アクセス制御は次のセキュリティルールで行います）。

### 3. Realtime Databaseのルールを設定する

Firebaseコンソールの「Realtime Database」→「ルール」タブで、以下の内容に置き換えて「公開」してください。友達内だけで遊ぶ想定の簡易的なルールです（誰でも部屋番号さえ知っていれば読み書きできます）。

```json
{
  "rules": {
    "rooms": {
      "$roomId": {
        ".read": true,
        ".write": true
      }
    }
  }
}
```

より厳密にしたい場合は、Firebase Authentication（匿名認証など）を追加して `auth != null` を条件にすることもできますが、このプロジェクトの実装では未使用です。

### 4. GitHub Pagesで公開する

このリポジトリには GitHub Actions のワークフロー（[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)）が既に入っています。

1. GitHubリポジトリの「Settings」→「Pages」を開きます。
2. 「Build and deployment」の「Source」を **GitHub Actions** に設定します。
3. `main` ブランチに `src/firebase-config.js` を書き換えた状態でpushすると、自動でビルド・デプロイされます。
4. 数分後、`https://<あなたのユーザー名>.github.io/wordotch/` でアクセスできるようになります（Pagesの設定画面にURLが表示されます）。

### 5. ローカルで動作確認する

ESモジュールを使っているため `index.html` を直接ダブルクリックでは動きません。簡易サーバーを立てて確認してください。

```bash
python -m http.server 8000
```

上記を実行後、ブラウザで `http://localhost:8000` を開いてください。

## 遊ぶとき

1. 誰か1人が「部屋を作る」を押し、表示された4文字の部屋番号を友達に共有します。
2. 友達はそれぞれ名前を入力し、「部屋に入る」から部屋番号を入力して参加します。
3. 3人以上集まったらホストが「ゲーム開始」を押します。
4. あとは画面の指示に従って進めるだけです。ラウンドごとに親は自動で持ち回りになります。

## ファイル構成

```
index.html          ページ本体
style.css           スタイル
src/app.js          画面表示・進行ロジック
src/db.js           Firebase Realtime Databaseとのやり取り
src/words.js         ワード・キジュンのオリジナルデータ
src/firebase-config.js  Firebaseの接続設定（要編集）
.github/workflows/deploy.yml  GitHub Pagesへの自動デプロイ
```

## 注意事項

- 本プロジェクトは既存のボードゲーム「ワードッチ」のゲームシステムに着想を得たファンメイドの非公式実装です。カードのワード・キジュンの文言はすべてオリジナルで作成しており、実際の商品の内容は含んでいません。
- 無料のFirebaseプランで想定される少人数での利用を想定しています。大人数・長時間の常時公開には向きません。
